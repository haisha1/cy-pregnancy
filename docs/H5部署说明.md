# 用户端 H5 与微信小程序双端发布

管理 Web 是运营后台，本项目 H5 是面向用户的工具页面，两个前端独立部署。H5 与小程序复用本仓库 uni-app 代码及现有 Java 用户服务，不新增后端或虚假登录。

## 当前能力边界

H5 保留现有游客工具和知识浏览；账号、档案及资料页继续遵守当前登录限制，不因为发布 H5 而绕过。具体入口以实际页面验证为准。浏览器不能调用小程序 uni.login 获取微信小程序 code，现有代码会提示切换微信小程序登录，不提供浏览器账号登录。普通浏览器微信登录需要独立 OAuth/账号方案，不能直接复用小程序 AppSecret。不要在前端配置放微信或 JWT 密钥。

健康记录仍保存在当前浏览器本地存储，换浏览器、IP 改域名、HTTP 改 HTTPS 都不会自动迁移；不要把 H5 本地记录视为已经云同步或已与小程序互通。需要时先使用现有备份导出功能。

## 文件与端口

| 文件 | 用途 |
| --- | --- |
| Jenkinsfile | App 仓库 H5 发布任务，复用 node22 工具 |
| deploy/h5/jenkins-build.sh | 测试、类型检查、H5 构建、镜像、健康检查及失败恢复 |
| Dockerfile.h5 | 仅打包 unpackage/dist/build/h5 |
| Dockerfile.h5.dockerignore | 排除源码、密钥、依赖及小程序构建产物 |
| compose.h5.yml | H5 容器、资源、共享网络和 18081 入口 |
| deploy/h5/nginx.conf | 静态资源和 /api/v1/ 到 user-api:18731 的同源代理 |

H5 使用 cy-pregnancy-h5 容器和镜像，管理 Web 保持 18080，H5 使用 18081；共享 cy-pregnancy-internal 网络。Nginx 在容器内监听 8080，不公开 internal、admin 或 actuator 路径。前端健康不代表 Java API 已正常。

## 本地构建

Node 22.12+，在 App 仓库根执行 npm ci、npm test、npm run typecheck、npm run build:h5。H5 产物是 unpackage/dist/build/h5，不是管理 Web 的 dist。当前 manifest H5 路由使用 hash，直接部署网站根目录即可。

H5 默认请求同源 /api/v1；Jenkins 脚本显式固定此值。小程序仍使用原 VITE_API_BASE_URL 配置及 build:mp-weixin，不被 H5 发布脚本修改。

## Jenkins 新建 H5 任务

1. 先提交并推送本次配置到 App 仓库。当前本地 origin 为 https://github.com/haisha1/cy-pregnancy.git，确认对应独立 App 仓库，不是上层工作区。
2. 新建 Pipeline，名称 cy-pregnancy-h5，Pipeline script from SCM → Git → 对应 App 仓库 SSH 地址，凭据 github-ssh，分支 */main，Script Path 填 Jenkinsfile。
3. Jenkins Tools 复用已有 node22（22.12+），执行节点复用 Docker CLI、Buildx 和 Compose；不需要 Java/JDK 工具。
4. 首次手动构建，验证首页和健康检查。GitHub 对 App 仓库添加现有 Jenkins /github-webhook/ 地址、application/json、push 事件；首次运行注册触发器后测试 push main 自动发布。与两个 Java 任务错开构建，避免小内存服务器资源争用。

## 访问方式与受限测试

大陆服务器网站的域名或 IP 对外提供服务均需符合备案要求，不能把 H5/IP 当作绕过小程序审核或网站备案的方式。当前默认绑定 `0.0.0.0:18081`，支持公网 IP 访问；受限测试时在 Jenkins 环境设置 `H5_BIND_ADDRESS=127.0.0.1` 并重新构建，只允许本机或 SSH 隧道访问。参见 [腾讯云备案场景](https://cloud.tencent.com/document/product/243/18910)。

电脑打开隧道并保持窗口运行（SSH 非 22 时加 -p 实际端口）：

~~~powershell
ssh -N -L 127.0.0.1:18081:127.0.0.1:18081 root@106.52.111.175
~~~

使用隧道时，在该电脑浏览器访问 http://127.0.0.1:18081，不需要放行公网 18081。

## 备案后域名和 IP 入口

宝塔 H5 域名站点整站反向代理到 http://127.0.0.1:18081，配置解析和 HTTPS。无需改容器即可支持域名；采用独立域名或子域名，当前不支持直接挂到任意 /h5/ 子路径。

默认公网 IP 入口为 `http://服务器公网IP:18081`，腾讯云安全组和服务器防火墙需按实际来源放行 TCP 18081；域名和 IP 会访问同一 H5 容器。如果 Jenkins 已配置 H5_BIND_ADDRESS=127.0.0.1，需移除该覆盖或改成 0.0.0.0，再重新构建。此环境变量是 Compose 端口绑定配置，不是前端 VITE 变量。域名入口的访问限制不会自动限制 IP 入口。

## 验收与后续

- 检查工具计算、深浅主题、窄屏、页面刷新和浏览器本地保存。
- 检查知识通过 /api/v1/ 从真实用户服务读取，内部接口不可访问。
- 微信登录在 H5 返回明确平台限制，不创建假账号；小程序真实登录继续等待正式域名/资质条件后验收。
- 小程序发行仍执行 build:mp-weixin，并在微信开发者工具上传、审核、发布；推送触发 H5 不会自动上线小程序。
- 更新失败恢复旧镜像不回退用户本地存储结构；发布数据格式变化前需检查既有备份兼容性。
