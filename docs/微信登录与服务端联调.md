# 微信游客模式与服务端联调

产品依据：2026-10-19用户要求“默认游客，仅进入档案提示登录，微信为主要平台”。该要求覆盖旧稿“登录仅用于未来云同步”的说明；医学公式、论文和模型门禁没有改动。

## 阅读代码

App.vue调用store/account.ts的hydrate，只恢复缓存，不请求微信或创建账号。ref是内存状态，Pinia在页面间共享；persist先写存储，成功才更新内存。

GaPage的requiresAccount保护档案概览、管理、详情、产检安排及账号资料页，深链也检查。游客看到共享GaAccountGate，可返回工具。工具、知识和「我的」不主动弹登录。它是本机页面交互门禁，不是健康数据加密方案。

点击微信登录后，账号store先读取真实capabilities，再由api/wechat.ts调用uni.login，把一次性code交给服务端。H5不能模拟微信身份。登录后/me返回公开UUID，不返回OpenID、session_key或身份散列。

GaAccountSummary默认显示图标及“微信用户”。pages/mine/account.vue提供chooseAvatar按钮、type=nickname输入和清除资料；头像昵称可跳过，也可手工填写昵称。微信处理原生隐私授权；拒绝或取消不退出账号，不索取手机号、定位或通讯录。

## 接口与边界

前缀/api/v1，JSON envelope为code/message/data/requestId。Bearer不放URL、日志、健康导出或分享。

| 接口 | 内容 |
| --- | --- |
| GET /capabilities | 游客可读；auth/accountProfile依据微信配置，sync等仍关闭 |
| POST /auth/wx-login | code、随机installationId，不允许客户端指定OpenID |
| POST /auth/refresh | 串行轮换refreshToken，绝对到期时间不延长 |
| POST /auth/logout | 撤销当前会话 |
| GET /me | userId为公开UUID，nickname、hasAvatar、profileRevision；cloudSyncEnabled=false |
| POST /me/profile | 无图片JSON，有图片multipart；nickname、wxCode、revision，可选avatar文件 |
| GET /me/avatar | 本人鉴权读取JPEG，no-store，无头像404 |
| DELETE /me/profile?revision=... | 清除头像昵称，旧版本409；账号和本机健康记录保留 |

新的wxCode仅在本次资料请求中用于匹配账号、调用msgSecCheck V2（scene=1），不新增OpenID明文持久化。昵称最多32个UTF-16代码单元，可空，不接受控制字符。审核不是pass或微信不可用都不保存。检查在数据库更新之前，以revision条件写入；409保留输入，需要明确重新加载。

头像由微信原生选择入口检查。服务端另行限制2MB、JPEG/PNG、最大4096边长和1600万像素；先读尺寸再解码，缩至最长256px，重编码JPEG移除EXIF。数据库保存，仅本人鉴权可读；客户端带Bearer下载临时文件再显示。文件校验不等于内容审核。目前没有公开头像/他人读取功能；未来公开展示前须增加mediaCheckAsync、回调验签和审核状态门禁。

verify合并并发读取，refreshFlight串行轮换。进入档案才联网确认；临近到期或明确401只刷新一次，普通503保留账号可重试。续期响应丢失时不能判断旧refresh是否已使用，清凭据重新登录，不自动重放。退出尝试撤销会话再清本机凭据；撤销未确认有提示。

本机健康记录不上传，不按微信账号同步或隔离；退出不自动删除。共享设备需在隐私与数据中导出或清理。登录不代表云同步，清除头像昵称也不等于注销账号。

## 本地和微信配置

H5运行npm run dev:h5，同源/api/v1代理18731。小程序开发运行npm run dev:mp-weixin，默认http://127.0.0.1:18731/api/v1仅用于本机开发者工具；真机的127.0.0.1指手机本身。

发布/真机前把.env.example复制为被忽略的.env.local，设置VITE_API_BASE_URL=https://实际域名/api/v1后重新构建。VITE变量进入客户端，禁止放Secret。小程序发布构建未配置地址时拒绝账号请求。manifest.json填真实mp-weixin.appid；服务端单独配置同一WX_APP_ID及WX_APP_SECRET，Secret不放前端。

微信后台配置HTTPS的request/uploadFile/downloadFile合法域名、服务端网络白名单及真实隐私保护指引。Nginx上传上限3MB。指引须由实际主体填写头像昵称用途、保存期限、联系与删除方式；页面技术说明不能代替正式指引。wx.openPrivacyContract打开后台真实指引，不伪造条款或默认勾选。

建议基础库2.29.1及以上。真机核验chooseAvatar、昵称快捷填写、nicknamereview、拒绝授权、取消选图、后台返回、退出/换账号以及iOS/Android表现；不使用getUserProfile/getUserInfo获取真实资料。

- 前端45项单测、20项H5浏览器回归，含原计算/本机CRUD、游客零请求、显式登录/取消、串行续期、深链、退出、未保存资料保护和401/503。旧功能账号边界使用夹具，游客能力查询访问真实服务。

- 类型、格式、设计lint、H5和mp-weixin构建；编译产物核对原生组件绑定。artifacts/account保存双主题截图与登录提示正文的axe结果（两主题均零违规），artifacts/account-static-audit.json记录严格静态检查零问题。
